# CGFC — памятка судьи и бойца

Статический сайт для быстрых турнирных памяток. Первая версия содержит:

- предварительную памятку по командному длинному мечу;
- алгоритм различения обоюдного, опережения, афтерблоу и позднего удара;
- отдельные чек-листы для судьи и бойца;
- каркас номинации «Кендзюцу» до получения новых правил.

## Локальный просмотр

Откройте `index.html` в браузере. Сборка и внешние зависимости не требуются.

## Публикация

Workflow `.github/workflows/pages.yml` публикует корень репозитория через GitHub Pages после каждого push в `main`.

## Источники

Черновик длинного меча основан на публичных материалах [Fencing Brain](https://purlakpv.github.io/fencing-brain/): общих правилах командных номинаций и личной номинации «Длинный меч».

Сайт является памяткой. При расхождении действуют положение турнира CGFC и последняя утверждённая редакция правил.
